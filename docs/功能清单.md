# JuggleMate Server · 功能清单

> 对应服务：`jugglemate-server`（Go 单体，模块 `github.com/juggleim/jugglemate-server`）
> 本文基于 `routers/router.go`、`main.go`、各 `services/*.go` 与根目录 `README.md` 归纳**已实现**能力。
> 部署/集成见 `docs/使用说明（部署与集成）.md`；二次开发见 `docs/二开开发文档.md`。

---

## 1. 能力总览

后端同时承载两件事：**① JuggleChat 分身 AI 平台（`/jim`）** 与 **② JuggleMate 客服系统（`/jmate`）**，并通过 JuggleIM 做实时消息中枢。以下按域列出。

---

## 2. 用户与鉴权

| 功能 | 接口 | 说明 |
|---|---|---|
| 用户注册 | `POST /jmate/user/register` | 返回 `user_id/role/authorization/im_token`；角色 1=客服、2=管理员 |
| 用户登录 | `POST /jmate/user/login` | 同上；每次登录刷新 `im_token` |
| 鉴权中间件 | `apis.Validate` / `consoleApis.Validate` | 读 `Authorization` / 控制台态 |

---

## 3. 客户入会话（C 端入口）

| 功能 | 接口 | 说明 |
|---|---|---|
| 启动会话 | `POST /jmate/customers/start` | 找/建 customer → 查 inbox/渠道 → 注册 IM 用户 → 建 IM 群（TicketId=GroupId）→ 建 ticket(pending) → 返回凭证 |
| 客户信息 | `GET /jmate/customers/info` | 客户维度详情 |
| 客户工单 | `GET /jmate/customers/tickets` | 客户历史工单 |

---

## 4. 工单（客服主线）

| 功能 | 接口 | 说明 |
|---|---|---|
| 工单列表 | `GET /jmate/tickets/list` | 支持渠道/状态/坐席过滤 |
| 认领 | `POST /jmate/tickets/:id/claim` | SQL CAS（`UPDATE WHERE status=pending`）自带抢单防护 + 失败回滚 + `jgm:ticketassign` 通知 |
| 转移 | `POST /jmate/tickets/:id/transfer` | 改派给其它坐席/团队 |
| 工单事件 | `GET /jmate/tickets/:id/events` | 状态变更流水（审计） |
| 工单评价 | `GET /jmate/tickets/:id/rating` | CSAT 评分查询 |
| 自动关闭 | `services.StartAutoCloseTicker` | 按 `last_user_msg_at` 阈值自动关单并发 `jgm:csat` 卡 |
| 转人工 | `services.SwitchTicketToHuman` | 把坐席拉进 Ticket 群、移出 Bot（注入 Agent 平台） |
| 标签 | `services.TicketGlobalTagService` | 工单全局标签 |
| CSAT 邀请 | `services.CSATInvitation` + `notifycsatinvitation` | 发评价邀请卡与重试 |

> 状态机：`pending / processing / resolved / reopened / closed`（closed 为 DB 隐藏终态，前端不可见）。

---

## 5. 坐席目录

| 功能 | 接口 | 说明 |
|---|---|---|
| 坐席列表 | `GET /jmate/seats/list` | 登录即可调用（不限 admin） |

---

## 6. 渠道与 Inbox（管理控制台）

| 功能 | 接口 | 说明 |
|---|---|---|
| 用户 CRUD | `/jmate/console/users` (GET/POST/PUT/DELETE) | 控制台账号管理 |
| Inbox 列表/详情 | `GET /jmate/console/inboxes`、`GET /:id` | 收件箱管理 |
| 创建 Inbox | `POST /jmate/console/inboxes/{telegram,juggleim,whatsapp,widget}` | 4 种渠道收件箱 |
| 更新/删除 Inbox | `PUT/DELETE /jmate/console/inboxes/:id` | — |
| Inbox 成员 | `GET/PUT /:id/members` | 成员管理 |
| Inbox-Agent 绑定 | `GET/PUT/DELETE /:id/agent` | 绑定/解绑默认 Agent（删除时清理群内 Bot） |

---

## 7. 渠道 Webhook（消息入站）

| 功能 | 接口 | 说明 |
|---|---|---|
| Telegram | `POST /jmate/webhooks/telegram/:inbox_id` | 渠道消息入站 → 建/续工单 |
| JuggleIM | `POST /jmate/webhooks/juggleim/:inbox_id` | 同上 |
| WhatsApp | `GET/POST /jmate/webhooks/whatsapp/:inbox_id` | GET 验证、POST 收消息 |
| 通用消息 | `POST /jmate/webhooks/message` | 通用 webhook |

---

## 8. Agent 平台 / 分身 AI（`/jim`，详见 `README.md`）

| 功能 | 接口 | 说明 |
|---|---|---|
| 创建/更新/删除分身 | `/jim/aibots/add` `/update` `/remove` | 分身 CRUD（owner 权限校验） |
| 我的分身列表 | `GET /jim/aibots/mybots` | 分页游标 |
| 素材 | `/jim/aibots/:unique_name/materials(/:id/remove)` | 素材增/查/删（text/url/file） |
| 训练 | `POST /jim/aibots/:unique_name/training` | 模式 `mind/memory/skill` |
| 任务/版本 | `/jim/aibots/:unique_name/jobs`、`/versions`、`/versions/:v/activate`、`/versions/current` | 训练任务、版本管理、激活 |
| 评估 | `GET /jim/aibots/:unique_name/evaluations` | 待实现（当前返回空） |

**Agent Session（协同/托管）**：由 Go Agent 平台提供，向控制台注册在 `/jmate/agentapi/*`（创建/查找/切换 agent/托管收回/流式聊天），供坐席端 Agent 面板调用。

---

## 9. 控制台统计

| 功能 | 接口 | 说明 |
|---|---|---|
| 总览 | `GET /jmate/console/stats/overview` | 客服数据总览 |
| Agent 统计 | `GET /jmate/console/stats/agents` | — |
| 客户统计 | `GET /jmate/console/stats/customers` | — |

---

## 10. IM 回调与实时

| 功能 | 接口 | 说明 |
|---|---|---|
| 消息回调 | `POST /botmsgs/msgcallback` | IM Server 回调入口；Node 可转发到 `/botmsgs/forward` |
| 群/Tag/系统消息 | `services/notifyservice.go` | `jgm:ticketassign` / `jgm:csat` / `jgm:ticket_resolved` 等 |
| 实时通道 | JuggleIM WebSocket | 建群、成员变更、消息推送（TicketId=GroupId） |

---

## 11. 基础设施

| 能力 | 说明 |
|---|---|
| Web 框架 | gin |
| 存储 | PostgreSQL（业务库）+ Redis（缓存/队列），经 Go Agent 平台统一接入 |
| 对象存储 | Aliyun OSS（知识库/附件，可配） |
| 知识库 | 向量化（`pgvector`，worker 消费组） |
| 静态资源 | `GET /static` 暴露 `./data`（头像等） |
| 控制台前端 | `console/web` 构建后内嵌服务 |
