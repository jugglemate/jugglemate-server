# JuggleMate Server · 使用说明（部署与集成）

> 对应服务：`jugglemate-server`（Go 单体）
> 本文讲**怎么把它跑起来、怎么跟前端集成**。详细 API 字段见 `README.md`（Bot/分身）与各 `docs/*-api.md`。
> 二次开发见 `docs/二开开发文档.md`；能力总览见 `docs/功能清单.md`。

---

## 1. 它在系统里的位置

```
   jugglemate-customer-chat (C 端 widget)  ─┐
                                           ├──►  jugglemate-server  ◄──  JuggleIM（实时消息）
   jugglemate-desktop (坐席工作台)        ─┘        (/jmate/* + /jim/* + /botmsgs)
                                               │
                                          PostgreSQL + Redis + 模型 Provider
```

- **C 端 widget** 调 `POST /jmate/customers/start` 启动会话、拿 IM 凭证。
- **坐席工作台** 调 `/jmate/tickets/*`、`/jmate/agentapi/*`、`/jmate/console/*` 等做客服操作与管理。
- **JuggleIM** 是实时消息通道；本服务通过 IM SDK 建群（TicketId=GroupId）、发系统消息、做回调。
- 同时本服务也是 **JuggleChat 分身 AI** 的后端（`/jim/*`，见根目录 `README.md`）。

## 2. 部署前置依赖

| 依赖 | 必选 | 说明 |
|---|---|---|
| PostgreSQL | ✅ | 业务库，DSN 见 `conf/config_example.yml` |
| Redis | ✅ | 缓存/队列 |
| JuggleIM Server | ✅ | 提供 IM HTTP API 与 WebSocket（Bot/群/消息） |
| 模型 Provider | ⚠️ | Agent 对话所需 LLM（不启 Agent 可关 `agent.enabled`） |
| Node ≥ 18 | 仅构建 | `build.sh` 会先构建 `console/web` 前端 |
| Aliyun OSS | 可选 | 知识库/附件对象存储（可换实现） |

## 3. 配置

复制样例并填写真实值：

```bash
cp conf/config_example.yml conf/config.yml
```

必填/重点（`conf/config_example.yml`）：

| 字段 | 示例 | 说明 |
|---|---|---|
| `port` | `8050` | HTTP 端口 |
| `imApiDomain` | `http://127.0.0.1:9001` | IM HTTP API 根；Bot token 由这里签发 |
| `jmateBaseUrl` | `http://127.0.0.1:8050` | 自身对外基址 |
| `agent.postgres.dsn` | `host=... user=postgres ...` | PG 连接串 |
| `agent.redis.address` | `127.0.0.1:6379` | Redis |
| `agent.auth.internalSecret` | `change-me-...` | JMate 转发共享密钥（生产必改） |
| `agent.security.secretKey/Salt` | — | 认证安全密钥（生产必改） |
| `agent.im.wsAddress` | `wss://127.0.0.1` | Bot 常驻 WS（须与 `imApiDomain` 同套 IM） |

> ⚠️ `internalSecret` / `secretKey` / `secretSalt` 默认值仅用于测试，生产必须覆盖。

## 4. 构建与启动

```bash
# 方式一：完整构建（含控制台前端）→ ./build/jchat-ai
./build.sh

# 方式二：只构建后端
CGO_ENABLED=0 GOOS=linux GOARCH=amd64 go build -o ./jchat-ai main.go

# 运行
./jchat-ai
# 或开发期：go run main.go
```

启动后：
- HTTP 监听 `:${port}`（默认 8050）。
- 控制台 Web 由 `console.LoadConsoleWeb` 内嵌提供（无需单独部署前端）。
- 上传静态资源暴露为 `GET /static`（映射到本地 `./data`）。
- IM 回调入口：`POST /botmsgs/msgcallback`（Node 服务可把原始消息转发到 `POST /botmsgs/forward`）。

## 5. API 分组与调用方

| 分组 | 路径前缀 | 调用方 | 说明 |
|---|---|---|---|
| 分身 AI | `/jim/*` | 分身管理端 / Agent 配置 | 创建/训练/版本/素材；详见 `README.md` |
| 客服域（公开） | `/jmate/webhooks/*` | 渠道侧（Telegram/JuggleIM/WhatsApp/通用） | 渠道消息入站 webhook |
| 客服域（鉴权） | `/jmate/user/*`、`/jmate/customers/*`、`/jmate/tickets/*`、`/jmate/seats/*` | **widget + 坐席端** | 登录、客户入会话、工单、坐席目录 |
| 控制台 | `/jmate/console/*` | 管理后台（Web） | 用户/Inbox/渠道/统计 CRUD |
| Agent 控制台 | `/jmate/agentapi/*` | 坐席端（Agent 面板） | 会话协同/托管/切换等本地接口 |
| IM 回调 | `/botmsgs/msgcallback` | JuggleIM Server | 消息回调（非客户端直调） |

### 5.1 与 customer-chat（widget）的集成点

- `POST /jmate/customers/start`：widget 启动即调，返回 `user_id / im_token / conversation_id / conversation_type`，用于自动连 IM。
- `inboxId` 由 widget 配置 `inboxId` 指定；`appId` 由 `JuggleChatConfig.appId` 指定。

### 5.2 与 desktop（坐席端）的集成点

- `POST /jmate/user/login`、`/user/register`：登录拿 `im_token` + `authorization`。
- `GET /jmate/tickets/list`、`POST /jmate/tickets/:id/claim`、`POST /jmate/tickets/:id/transfer`：工单认领/转移。
- `GET /jmate/seats/list`：坐席目录。
- `GET /jmate/customers/info`、`/customers/tickets`：客户维度信息。
- `/jmate/agentapi/*`：Agent 协同/托管/切换、SSE 流式建议。
- `/jmate/console/*`：管理端配置渠道、Inbox、成员、看统计。

## 6. 认证

- 客户端接口：请求头带 `Authorization`（登录返回的 JWT）；由 `apis.Validate` 校验。
- 控制台接口：由 `consoleApis.Validate` 校验（管理态）。
- 内部转发：JMate 转发到 Agent 原生入口时携带 `internalSecret`，Agent 端只信任该密钥。
- 统一响应结构：`{ "code": 0, "msg": "success", "data": {} }`；非 0 为错误（错误码见 `README.md` 末表，如 `17012` 用户不存在、`17602` 分身不存在）。

## 8. 部署注意

- **CORS**：当前 `corsHandler` 全开（`*`），生产环境应收紧来源。
- **静态资源**：`/static` 映射到 `./data`，注意权限与容量。
- **Agent 模块**：`agent.enabled=false` 时 `/jmate/agentapi/*` 返回不可用错误（不会回退到已下线的 Python agent-server）。
- **自动关闭**：启用 Agent 时后台 ticker 会按阈值自动关单并发 CSAT 卡，确认 `last_user_msg_at` 逻辑符合预期。
- **密钥**：生产必须覆盖 `internalSecret` / `secretKey` / `secretSalt`，不要提交真实值到仓库。
